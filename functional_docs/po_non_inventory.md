**Summary:**

<!-- SUMMARY:model:po_non_inventory -->
Purchase Order (Non-Inventory) is created by BugFix-Purchase. This repo adds two qweb-pdf print actions, both named Purchase Order (Non-Inventory) Report, that use Studio report templates. It also adds nine access rights: procurement end users and Non-Inventory Credit invoicing/payment groups can create and edit, the NI invoice journal group can read and write, and accounting executives, cashiers and the view-only groups can read.
<!-- /SUMMARY -->
