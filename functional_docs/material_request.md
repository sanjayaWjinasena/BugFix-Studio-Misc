**Summary:**

<!-- SUMMARY:model:material_request -->
This repo only adds nine access rights on Material Requests for the Jin maintenance, manufacturing and repair (helpdesk) groups defined in this repo. They range from read-only for the minimum-rights and view-only groups, to read and create for Maintenance users, to read, write and create for MO Creator, Production Orders Dismantler and Repair Ticket Creater. The model itself comes from BugFix-Stock.
<!-- /SUMMARY -->
