**Summary:**

<!-- SUMMARY:model:x_pr_non_inventory -->
Purchase Request (Non-Inventory) is created by BugFix-Purchase. This repo adds an approval rule, Approve PR - Non-Inventory, which needs approval from the Jin Non-Inv PR Approvers group. It also adds access rights: the PR Administrator gets full access, Non-Inv PR creators and approvers get read/write/create, procurement end users get read/write, and the remaining groups are read-only.
<!-- /SUMMARY -->
