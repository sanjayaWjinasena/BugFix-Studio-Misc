**Summary:**

<!-- SUMMARY:model:x_purchase_request -->
Purchase Request is created by BugFix-Purchase. This repo adds two approval rules that need the PR Approval group: Confirm PR, and Done PR + Copy PR to RFQ. It also adds the Purchase Request Report - 12345 qweb-pdf print action and ten access rights for purchase and sales groups. Two record rules limit procurement end users to their own type: Imports users can only read and write requests whose type is Import, and Local users only those whose type is Local.
<!-- /SUMMARY -->
