**Summary:**

<!-- SUMMARY:model:purchase_request_lin -->
Purchase Request Line is created by BugFix-Purchase. This repo only adds access rights: the PR Administrator gets full access, Inv PR creators and procurement end users get read/write/create, and Non-Inv PR creators and the view-only groups get read-only access.
